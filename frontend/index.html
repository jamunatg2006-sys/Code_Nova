MISSION RULES & SCORING 📜

Everything you need to master OopsieFlip and climb the leaderboard.

🃏

1. The Gameplay Loop

Enter your unique nickname and choose a challenge level. When the timer begins, click face-down cards to flip them. Flip two matching symbols in succession to lock them open!

⚡

2. Difficulty Modes

Easy: 8 cards (4 pairs) — Great for a quick warm-up (1.0× multiplier).
Medium: 16 cards (8 pairs) — Balanced challenge (1.5× multiplier).
Hard: 24 cards (12 pairs) — Intense concentration test (2.0× multiplier).

🎯

3. Scoring Breakdown

Your score is calculated based on:
• Base Points: 300 pts per matched pair.
• Speed Bonus: Finishing swiftly earns high time bonuses.
• Move Efficiency: Unnecessary flips reduce score.
• Multiplier: Multiplied by your difficulty scale!

🏆

4. Leaderboard Ranking Rules

Scores are stored in MongoDB. Operatives with the highest scores rank first. In case of a points tie, the player with the lower completion time ranks higher!

ABOUT OOPSIEFLIP ℹ️

Collaborative Full-Stack Project — Code Nova Team

🛠️ Technology Stack

  • Frontend: Semantic HTML5, Modular CSS3 (Neon Cyberpunk Design System), Vanilla JavaScript (ES6+).
  • Backend: Node.js, Express.js REST API with robust payload validation and error handling.
  • Database: Native MongoDB driver connecting to MongoDB Atlas cloud database with compound indexing.
  • Audio: Native Web Audio API synthesizer for real-time sound effects without external downloads.

📡 Live Backend API Endpoints

  • GET /api/health — Health check & DB connection monitor.
  • GET /api/scores/leaderboard — Filterable, paginated high scores.
  • POST /api/scores — Validated submission of game results.
